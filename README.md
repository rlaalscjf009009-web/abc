# 빗썸 종목 검색기 (PWA)

## 설치
1. 폴더 내용을 HTTPS를 지원하는 정적 호스팅에 업로드합니다. 예: GitHub Pages.
2. Android Chrome에서 배포된 HTTPS 주소를 엽니다.
3. Chrome 메뉴에서 `앱 설치` 또는 `홈 화면에 추가`를 누릅니다.

로컬 파일을 Chrome에서 직접 여는 것만으로는 PWA 설치가 되지 않습니다. HTTPS 호스팅이 필요합니다.

## 저장 및 기능
- 검색 기록, 월별 성공 종목, 목표가 도달 기록은 브라우저 localStorage에 저장됩니다.
- 브라우저 데이터 삭제 또는 앱 데이터 초기화 시 기록이 사라질 수 있습니다.
- 검색은 Bithumb 공개 API에 직접 요청하므로 API의 CORS 정책과 요청 제한에 영향을 받습니다.
- 조건: 현재 월봉 고가가 전월 종가보다 낮은 종목을 표시합니다.
- 목표가: 전월 종가의 99.7% (전월 종가 - 0.3%).
